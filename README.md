# Kiosk Beach — cardápio virtual

Cardápio responsivo em HTML, CSS e JavaScript, com pedidos preparados para o WhatsApp.

## Abrir no computador

Abra `index.html` no navegador. Mantenha `logo-kiosk-beach.png` na mesma pasta para o logo aparecer.

## Enviar ao GitHub

Crie um repositório **privado** no GitHub. Em **Add file → Upload files**, envie os três arquivos desta pasta e clique em **Commit changes**. O GitHub guarda os arquivos; não é preciso ativar GitHub Pages para continuar usando o link privado já hospedado.
